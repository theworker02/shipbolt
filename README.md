# shipbolt

Ship digests and bolt fingerprints for local integrity checks.

**Site:** https://theworker02.github.io/shipbolt/

## Install / run

```bash
git clone https://github.com/theworker02/shipbolt.git
cd shipbolt
node src/cli.js
node --test
```
